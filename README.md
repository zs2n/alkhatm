# الختم

لعبة بيكسل آرت لليوم العالمي لمكافحة الفساد. أنت موظف جديد في إدارة المشتريات: افحص كل معاملة، طابقها مع اللائحة، ارفض الرشوة، واختم بالقرار الصحيح.

من إنشاء استوديو قرطاس.

- العب: https://zs2n.github.io/alkhatm/
- اللعبة كلها في `docs/` كموقع يشتغل من الجوال مباشرة، ويقدر اللاعب يضيفه للشاشة الرئيسية.
- `poster-alkhatm.png` ملصق الفعالية بالباركود، و`qr-alkhatm.png` الباركود لحاله.

## التحكم

- الجوال: المعاملة تنفتح تلقائيًا واللائحة تحتها، والختم من أزرار أسفل الورقة.
- الكيبورد: → اعتماد · ← رفض · R اللائحة · Q رد الظرف · E خذ الظرف · Enter التالي.
- يد التحكم: A اعتماد · B رفض · X فحص · Y اللائحة · LB/RB الظرف.
