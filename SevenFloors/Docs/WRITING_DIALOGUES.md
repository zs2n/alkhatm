# دليل كتابة الحوارات والأحداث

كل حوار = ملف JSON في `Assets/Game/Resources/Data/Dialogues/`
اسم الملف (بدون الامتداد) هو **معرف الحوار** الذي تستدعيه من أي مكان.

## الهيكل الأساسي

```json
{
  "id": "my_dialogue",
  "lines": [
    { "sp": "", "text": "سطر سرد بدون متحدث." },
    { "sp": "hero", "exp": "default", "text": "سطر يقوله البطل." },
    { "sp": "old_man", "exp": "angry", "text": "سطر يقوله العجوز بتعبير غاضب.", "end": true }
  ]
}
```

## كل حقول السطر (كلها اختيارية عدا `text`)

| الحقل | النوع | الوظيفة |
|---|---|---|
| `sp` | نص | معرف المتحدث من `characters.json`. فارغ = سرد بدون اسم |
| `exp` | نص | اسم التعبير = اسم ملف الصورة (افتراضياً `default`) |
| `side` | نص | `auto` (افتراضي: البطل يمين والبقية يسار) أو `left` أو `right` |
| `text` | نص | نص السطر |
| `label` | نص | علامة يمكن القفز إليها |
| `gotoLabel` | نص | بعد هذا السطر اقفز إلى العلامة |
| `ifFlag` | نص | نفّذ `gotoLabel` فقط إذا تحقق الشرط (انظر الرايات) |
| `choices` | قائمة | خيارات للاعب — انظر أدناه |
| `setFlag` | نص | اضبط راية: `"met_neighbor"` أو `"trust=2"` |
| `bg` | نص | غيّر الخلفية: `"Art/Backgrounds/lobby"` |
| `cg` | نص | اعرض مشهد CG فوق الشاشة، و`"-"` يزيله |
| `music` | نص | شغّل موسيقى `"Audio/Music/tension"`، و`"-"` يوقفها |
| `sfx` | نص | مؤثر صوتي `"Audio/SFX/door_slam"` |
| `voice` | نص | تسجيل صوتي للسطر `"Audio/Voice/hero/l01"` |
| `shake` | منطقي | هزة شاشة مع السطر |
| `hide` | منطقي | أخفِ المتحدث بعد السطر |
| `hideAll` | منطقي | أخفِ كل الشخصيات |
| `end` | منطقي | أنهِ الحوار بعد هذا السطر |
| `advanceDay` | منطقي | بعد انتهاء الحوار انتقل لليوم التالي |

## الخيارات والتفرعات

```json
{ "sp": "hero", "text": "ماذا أفعل؟", "choices": [
    { "text": "افتح الباب", "gotoLabel": "open_door", "setFlag": "opened" },
    { "text": "تجاهل الطرق", "gotoLabel": "ignore" }
] },
{ "label": "open_door", "sp": "", "text": "فتحتُ الباب...", "gotoLabel": "after" },
{ "label": "ignore", "sp": "", "text": "تظاهرت بأنني لم أسمع شيئاً." },
{ "label": "after", "sp": "", "text": "يستمر الحوار من هنا.", "end": true }
```

## الرايات (Flags) — ذاكرة القصة

- الضبط: `"setFlag": "saw_monster"` (تساوي 1) أو `"setFlag": "trust=3"`.
- الفحص في `ifFlag` أو في `requireFlag` لنقاط التفاعل:
  - `"saw_monster"` → الراية موجودة وقيمتها ليست صفراً.
  - `"saw_monster=0"` → غير موجودة أو صفر.
  - `"trust=3"` → تساوي 3 بالضبط.
- قفزة شرطية:
```json
{ "sp": "", "text": "نظر إلي طويلاً...", "ifFlag": "helped_barricade", "gotoLabel": "friendly" }
```
- الرايات تُحفظ تلقائياً ضمن ملف الحفظ.

## ربط الحوارات باللعبة

| أين | كيف |
|---|---|
| حوار بداية اللعبة | `game.json` → `"startDialogue"` |
| افتتاحية يوم | `days.json` → `"intro"` لكل يوم |
| نقطة تفاعل (شخصية/باب/شيء) | `locations.json` → حقل `"dialogue"` في النقطة |
| نهاية | ملف يبدأ اسمه بـ `ending` — عند انتهائه يعود اللاعب للقائمة الرئيسية |

## نقاط التفاعل في المواقع (`locations.json`)

```json
{ "x": 0.44, "y": 0.20, "w": 0.11, "h": 0.46,
  "label": "باب الشقة", "type": "door", "target": "corridor_3f",
  "requireFlag": "", "setFlag": "", "minDay": 0, "maxDay": 0 }
```

- الإحداثيات منسوبة للشاشة: `x,y` الزاوية العليا اليسرى (من 0 إلى 1)، `w,h` العرض والارتفاع.
- الأنواع: `door` / `stairs` / `elevator` (تنقّل عبر `target`) ، `character` (حوار) ، `object` (فحص بـ`text` أو حوار) ، `tv` (نشرة الأخبار) ، `bed` (إنهاء اليوم) ، `exit`.
- `minDay` و`maxDay` لإظهار النقطة في أيام محددة، و`requireFlag` لإظهارها حسب راية — وبهذين تُبنى الأحداث اليومية.
